Compagnon de jeu du 10 000 — 100 % hors ligne

⬇ Télécharger l'APK (Android) Voir le code sur GitHub

Distribution directe en attendant la publication sur le Play Store. Android bloque par défaut les APK hors Play Store : voir les 3 étapes d'installation ci-dessous.

Ça fait quoi ?

🎯

Toutes les règles gérées

Sortie à 300, pile de gains, 3 cœurs, rencontre, dernière chance — l'appli applique les règles à ta place.

📱

Fait pour la table

Tuiles géantes, scores qui grimpent en s'animant, lisibles de loin, posées au centre du jeu.

🔒

100 % hors ligne

Aucune connexion, aucun compte, aucune donnée envoyée. Tout reste sur le téléphone.

💀

Un mode caché

Une seconde personnalité de l'appli, plus mordante, à débloquer en secret pour les soirées corsées.

Installer l'APK

  1. Télécharge le fichier 10K.apk avec le bouton ci-dessus (depuis le téléphone, dans Chrome).
  2. Ouvre le fichier téléchargé : Android va demander d'autoriser l'installation depuis cette source — accepte.
  3. Si « Play Protect » affiche un avertissement, choisis « Installer quand même » — l'appli n'a aucune permission ni connexion, l'avertissement vient juste du fait qu'elle n'est pas encore sur le Play Store.
